# Missed Call Rescue — Commercial Developer Kit

A reusable Twilio missed-call text-back workflow for local service businesses.

## Included
- Incoming call router
- Missed-call handler
- Customer SMS reply forwarding
- Generic configuration example
- Installation checklist

## Required customer-owned configuration
- Twilio account and number
- BUSINESS_PHONE
- BUSINESS_NAME
- RING_TIMEOUT_SECONDS
- Optional message templates

## Security / privacy boundary
This package contains no FlowLink credentials, customer records, API keys, wallet addresses, payment links, or production environment values. Buyers must supply their own Twilio credentials and comply with applicable messaging, consent, privacy, and telemarketing rules.
